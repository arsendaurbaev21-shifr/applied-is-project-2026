Зертханалық жұмыс 1
Қолданыстағы QazCargo жүк тасымалдау жүйесіне зертханалық модуль қос.
Flask + SQL Server негізгі серверін сақта. Python модульдерін database,
routers, FastAPI main және Streamlit frontend қабаттарына бөл.
4 негізгі нысан: Clients, Orders, CargoTypes, CargoItems. Қолданыстағы
RouteID/TariffID байланыстарын сақтау үшін көмекші анықтамалықтарды енгіз.
requirements-labs.txt, .gitignore, іске қосу командалары және ER схемасын дайында.

Зертханалық жұмыс 2
QazCargo оқу моделін SQLModel арқылы іске асыр. PK/FK, екіжақты Relationship,
Clients–Orders 1:N және Orders–CargoTypes N:M байланыстары болсын.
CargoItems — салмақ, көлем және дана саны бар аралық модель.
SQLite базасын негізгі SQL Server-ден оқшаула; әр кестеге 3–5 жасанды жазба
енгізетін, қайта орындағанда деректі бұзбайтын seed жаса. echo=True қолдан.
FK, теріс салмақ, қайталанған тапсырыс нөмірі, Decimal және API-ді тексер.

Тексеру қағидалары
AI нәтижесі бастапқы SQL DDL-мен салыстырылды; FK және сандық шектеулер
автоматты тексерілді. SQL Server-дің триггерлері SQLite-ке көшірілді деген
тұжырым жасалмайды. Нақты аккаунттар, тапсырыстар және құпиялар жарияланбайды.
