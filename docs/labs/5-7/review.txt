5–7 КОД ШОЛУЫ ЖӘНЕ ТҮЗЕТУЛЕР
1. Бұрынғы UI тек оқуға жарайтын: форма, PATCH, растаулы DELETE қосылды.
2. Backend қолжетімсіздігі интерфейсті құлатуы мүмкін: ApiError, timeout және st.error қосылды.
3. Қайталанған POST дубль туғызуы мүмкін: жазу автоматты қайталанбайды; timeout хабарламасында тізімді тексеру түсіндірілді.
4. Контейнерді жою SQLite-ті жоғалтар еді: LAB_DATABASE_PATH және named volume енгізілді.
5. depends_on тек іске қосу кезегін шешетін: backend healthcheck және service_healthy қосылды.
6. .env/venv образға түсу қаупі: build context allowlist, минималды тәуелділіктер, root емес қолданушы.
7. Жалпы pytest SQL Server-ге тәуелді еді: әдепкі жинақ оқшауланған оқу тесттеріне бағытталды, SQL fixture импорттары кейінге қалдырылды.
8. Actions-та inline YAML командасындағы қос нүкте қате берді: block scalar арқылы түзетілді. Келесі run сәтті өтті.
Шектеулер: оқу API-інде login/RBAC жоқ, localhost үшін; негізгі жүйеде бөлек авторизация бар.
Тек автоматты тесттен өту толық қауіпсіздік аудитін алмастырмайды.
