QAZCARGO 5–7 БАҚЫЛАУ СҰРАҚТАРЫ
Даурбаев Арсен, ИС-24А

5-ЗЕРТХАНА

1. Streamlit пен FastAPI қалай байланысады?
Streamlit сервері requests арқылы FastAPI-ге HTTP сұрауын жібереді. Тізім GET арқылы, жаңа тапсырыс POST арқылы алмасады. Сұрау және жауап денесі JSON форматында беріледі; FastAPI SQLModel арқылы SQLite-ке жазады.

2. requests ішіндегі params және json айырмашылығы қандай?
params URL-дегі query параметрлерін құрады: search, min_price, limit. json Python сөздігін JSON сұрау денесіне айналдырады; ол POST, PATCH кезінде тапсырыс өрістерін жеткізеді.

3. Backend тоқтаса пайдаланушы не көреді?
ConnectionError немесе Timeout ApiError-ға айналады да, st.error түсінікті хабарлама көрсетеді. Құпия техникалық traceback шығарылмайды. POST timeout болғанда жазба сақталуы мүмкін, сондықтан қайта жібермес бұрын тізім тексеріледі.

4. Streamlit неге скриптті қайта орындайды?
Виджет өзгергенде скрипт жоғарыдан төмен қайта орындалады. st.form ішіндегі өрістер submit басылғанша бірге жиналады. st.session_state бөлімді, беттеу индексін және бір рет көрсетілетін хабарламаны сақтайды.

5. Streamlit пен HTML CSS JavaScript тәсілдерін салыстырыңыз
Streamlit Python арқылы форма мен деректер кестесін тез құруға ыңғайлы. Күрделі дизайн, ұсақ браузер әрекеттері мен үлкен пайдаланушы ағындарын толық басқару үшін жеке frontend көбірек мүмкіндік береді. Бұл жобада Streamlit оқу интерфейсіне, бастапқы веб-технологиялар негізгі Cargo сайтына қолданылды.

6-ЗЕРТХАНА

1. Контейнер виртуалды машинадан несімен ерекшеленеді?
Контейнер қолданба мен тәуелділіктерді оқшаулайды және хост ядросын пайдаланады. Виртуалды машина жеке операциялық жүйе ядросын жүктейді. Windows-та Linux контейнерлері Docker Desktop-тың Linux ортасында орындалады.

2. EXPOSE WORKDIR COPY CMD және RUN не істейді?
WORKDIR жұмыс каталогын, COPY көшірілетін файлдарды белгілейді. RUN образ жинау кезінде команданы орындайды, CMD контейнер қосылғандағы әдепкі команданы береді. EXPOSE портты сипаттайды, оны хостқа жариялау Compose ports арқылы жасалады.

3. dockerignore не үшін қажет?
Ол build context-ке қажетсіз және құпия файлдардың түсуін шектейді. Жергілікті venv көшірілсе образ үлкейіп, Windows бинарлық файлдары Linux-та жұмыс істемеуі мүмкін. Сондықтан кітапханалар контейнер ішінде requirements арқылы орнатылады.

4. backend атауы IP адреске қалай айналады?
Compose ортақ желі құрады. Docker-дің ішкі DNS қызметі backend сервисінің атауын оның контейнер адресіне сәйкестендіреді. Frontend контейнерінде localhost сол frontend-тің өзіне сілтейді.

5. down командасынан кейін SQLite сақтала ма?
Тек контейнер қабатындағы файл контейнер жойылғанда жоғалады. Бұл жобада /data named volume-ге жалғанғандықтан кәдімгі down деректі сақтайды. down -v volume-ді де өшіреді; CI оны тек өзіне тиесілі уақытша стек үшін қолданады.

7-ЗЕРТХАНА

1. Автоматты және қолмен тестілеудің айырмашылығы қандай?
Автотест бірдей шарттарды жылдам қайталап, күтілген жауаппен салыстырады. Қолмен тексеру экранның оқылуын, пайдаланушы әрекетін және күтпеген сценарийлерді бағалайды. Екеуі осы жобада бірге қолданылды.

2. TestClient Uvicorn іске қоспай қалай жұмыс істейді?
TestClient ASGI қолданбасын процесс ішінде шақырады; желілік порт қажет емес. with TestClient(...) lifespan іске қосылуын да тексереді. Тест үшін бөлек SQLite engine беріледі.

3. httpx не үшін қажет?
FastAPI TestClient Starlette арқылы httpx клиентінің интерфейсін пайдаланады. Ол тестте HTTP әдістері, headers, JSON және статус-кодпен жұмыс істеуге мүмкіндік береді. Бұл нақты TCP желісінің жұмысын толық тексермейді, сондықтан Docker HTTP тексеруі бөлек бар.

4. AI код шолуын толық алмастыра ала ма?
AI ықтимал қателерді ұсынады, бірақ талапты қате түсінуі немесе жағдайды өткізіп алуы мүмкін. Ұсынылған түзетулер кодпен салыстырылып, тестпен және нақты іске қосумен дәлелденуі тиіс. AI нәтижесі қауіпсіздік кепілдігі емес.

5. Регрессиялық тест деген не?
Жаңа өзгерістен кейін бұрын жұмыс істеген функцияның бұзылмағанын тексеру. 1–4 жұмыстың 26 тесті сақталып, UI, HTTP және persistence тесттерімен бірге орындалады. GitHub Actions әр тиісті push пен pull request кезінде тексеруді қайталайды.
