8 ЗЕРТХАНА — ҚАУІПСІЗДІК ШОЛУЫ

Шекара: FastAPI оқу модулі және Flask-тың нақты уақытша SQL Server тест базасы.
Негізгі QazCargo пайдаланушыларының жазбалары өзгертілген жоқ.

Нақты SQL Server сценарийлері: tests/test_lab8_security_sql.py.
10 тест өтті (19.49 секунд): бос/қысқа/кең тараған/қайталанатын пароль — 400;
жоқ логин және бос пароль — 401; сессиясыз admin ресурс — 401;
client -> admin — 403, admin -> admin — 200; бұғатталған клиент сессиясы — 401;
қате JSON — 400; CSRF жоқ — 403; пароль жауап пен caplog-та жоқ.
JUnit: security-sql.xml.

АНЫҚТАЛҒАН ЖӘНЕ ТҮЗЕТІЛГЕН
1. Пароль тек 10–128 ұзындығымен тексерілетін. password123 және 1111111111
   қабылданатынын регрессиялық тест анықтады. Енді шағын белгілі әлсіз мәндер
   тізімі мен төрттен аз әртүрлі таңбалы мәндер қабылданбайды. Жаңа қате KZ/RU/EN
   интерфейсіне аударылды. Бар парольдер/аккаунттар өзгертілмеді.
   Шектеу: бұл толық breached-password базасы немесе MFA емес.
2. FastAPI валидация жауабынан input/ctx алынып тасталды: бөгде Password өрісіндегі
   құпия маркер жауапта да, журналда да жоқ. Қате синтаксисті JSON — 400,
   семантикалық қате — 422. SQL қателері 409 жалпы хабарламасына айналады.
3. verify_db.py ішіндегі assert тексерулері Python -O кезінде жоғалар еді.
   Олар айқын ValueError тексерулеріне ауыстырылды.

СТАТИКАЛЫҚ ТАЛДАУ
Bandit 1.9.4. labs/lab_1_2 runtime коды; test_lab.py/test_crud.py тесттерін алып тастау.
Алдында: verify_db.py ішінде 7 LOW B101. Кейін: 0 finding.
Бұл нәтиже Bandit танитын үлгілермен шектеледі; толық қауіпсіздік кепілдігі емес.

Негізгі backend бойынша толық скан: bandit-primary.json.
15 MEDIUM B608 және 5 LOW B101 ескертуі бар; олар жасырылмады.
B608 қолмен қаралды: auth-та PUBLIC_USER тұрақтысы; db.insert-та идентификаторлар
ішкі константа/allowlist; portal-та CATALOGS және тексерілген өрістер;
documents-та META тұрақтысы, visibility және тұрақты фильтр атаулары;
usability-де тек рөлге байланысты тұрақты scope. Пайдаланушы мәндері ? параметрімен
жіберіледі. Қаралған жолдарда енгізілген мәннің SQL мәтініне тікелей жалғануы табылмады.
Бұл болашақ өзгерістерге кепіл емес; кеңейтілген аудитке арналған бастапқы тізім сақталды.
B101 backend/network.py ішіндегі жергілікті offline дерек файлын тексеруге қатысты;
осы кезеңде өзгертілмеді. Ол production HTTP рұқсат тексеруі емес.

ҚАЛҒАН ШЕКТЕУЛЕР
Оқу FastAPI-де login/RBAC жоқ, сондықтан оны жергілікті оқу деректерімен қолдану керек.
Негізгі сайттың жергілікті HTTP режимінде Secure cookie false; жария HTTPS режиміне
арналған share конфигурациясы оны true етеді. CSRF және HttpOnly қолданылады.
Жүктеме нәтижелері бір Windows компьютерінде және 200 тапсырыс көлемінде алынған.
