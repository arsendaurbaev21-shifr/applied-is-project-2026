SHARE_START.bat файлын ашыңыз. Алғашқы рет ресми Cloudflare клиенті
GitHub cloudflare/cloudflared релизінен qa/share ішіне жүктеледі.
Жүктелген EXE файлының SHA256 мәні тексерілгеннен кейін ғана іске қосылады.
Windows-қа қызмет орнатылмайды, роутер немесе firewall баптауы өзгермейді.

Терезеде https://...trycloudflare.com адресі шыққан соң сол сілтемені
жіберіңіз. Ағымдағы сілтеме SHARE_LINK.txt ішінде де сақталады.
Бұл уақытша қызмет: сілтеме қайта қосқанда өзгереді, үздіксіз жұмысқа
кепілдік берілмейді. Компьютер, интернет және іске қосқан процесс қосулы тұрсын.

Келуші сайттағы Кіру → Тіркелу арқылы өз клиент аккаунтын жасайды.
Тіркелулер мен тапсырыстар сол QazCargo SQL базасына жазылады.
Әкімшіге кіру үшін SET_ADMIN.bat арқылы жасаған жеке әкімші аккаунты керек.
Әкімшінің email/паролін жалпы сілтемеге қосып жібермеңіз.

Тоқтату: SHARE_START ашқан терезеде Ctrl+C басыңыз. Launcher өзінің
cloudflared және уақытша Python серверін тоқтатады. Күнделікті жергілікті
START.bat серверіне және SQL базасының деректеріне тимейді.
ChatGPT іске қосқан жағдайда осы чатта «уақытша сілтемені тоқтат» деп айтыңыз.

Техникалық құрылым:
HTTPS Cloudflare URL → loopback 127.0.0.1:5002 → Python → QazCargo SQL.
Әр іске қосуда тек берілген нақты hostname қабылданады. Secure, HttpOnly,
SameSite=Lax cookie және бастапқы CSRF/рөл/иелік тексерістері сақталған.
Сырттан жіберілген forwarding headers қабылданбайды.
127.0.0.1:5000 жергілікті режимі бұрынғыдай бөлек жұмыс істейді.

Тексеру: tests/test_share.py — 7 passed.
Нақты SQL бар уақытша тест базасында тіркелу, кіру және клиентке admin
API-ының жабық болуы тексерілді. Host, Secure cookie, CSRF және spoofed
forwarding header жағдайлары тексерілді. Жұмыс базасына тест аккаунты жасалмады.

Нақты жария HTTPS сілтемесімен қосымша тексерілді: басты бет HTTP 200;
QazCargo SQL health — ok=true, 17 кесте; 7 маршрут; калькулятор — 196503.75;
Secure cookie; CSRF бар logout — 200; бос тіркелу нысаны және жоқ аккаунтқа
кіру күтілген қателермен тоқтатылды. Сыртқы HTTP сұрауларда TLS сертификаты
тексерілді. Бұл тексеріс жұмыс базасына жаңа аккаунт/тапсырыс қоспады.
