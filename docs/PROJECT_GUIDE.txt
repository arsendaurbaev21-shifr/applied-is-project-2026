QAZCARGO ЖОБА КАРТАСЫ

run.py
Толық Visual Studio үшін Python entry point.

backend/app.py
Flask қолданбасын жинайды, HTTP беттерін береді, CSRF/host/қате өңдеуді орнатады; Waitress серверін іске қосады.

backend/db.py
pyodbc қосылымы, SQL параметрлері, нәтижелер, транзакция және write құлпы.

backend/auth.py
Кіру, тіркелу, пароль хеші, қате әрекет шектеуі, AuthVersion, рөл және бұғаттау.

backend/schema.py
Каталог allowlist-і, өріс типтері, мәтін/сан/email/күн валидациясы және жергілікті уақытты UTC-ге түрлендіру.

backend/service.py
Тапсырыс иелігі, Decimal баға, жүк, мәртебе және рейс операциялары.

backend/portal.py
Public каталог, әкімші CRUD, клиент профиль/тапсырыс, төлем, қолдау, есеп және CSV API.

backend/documents.py
Файл тексеруі, SQL байт сақтау, иелік тексеруі және қауіпсіз preview.

backend/install.py
Алғашқы .env, SQL batch орындау, COPY_ONLY backup, VERIFYONLY және дәл атпен reset.

backend/manage.py
Жергілікті консольден әкімші жасау/пароль қалпына келтіру және резерв.

backend/errors.py
Біркелкі код/HTTP мәртебесі/өріс бар қате моделі.

web/index.html
Басты бет, калькулятор, бағыттар, қызметтер, қадамдар.

web/login.html
Кіру мен клиент тіркеу бетінің қаңқасы.

web/admin.html
Бөлек әкімші кабинетінің қаңқасы.

web/customer.html
Бөлек клиент кабинетінің қаңқасы.

web/styles.css
Адаптивті дизайн, форма, кесте, мәзір және диалог стилі.

web/i18n.js
KK/RU/EN интерфейс, мәртебе, сервер қатесі және форма атаулары.

web/shared.js
fetch, CSRF, сессия, ортақ форма/кесте/диалог, сан/уақыт пішімі, баспа.

web/public.js
Басты калькулятор және кіру/тіркелуден кейін таңдауларды тасымалдау.

web/workspace.js
Кабинет навигациясы, бөлім маршруты және қауіпсіз автоматты жаңарту.

web/orders.js
Шолу, тапсырыс тізімі/формасы/карточкасы, жүк, рейс, төлем және баспа.

web/catalogs.js
SQL анықтамалықтарын схема бойынша басқару формалары.

web/office.js
Файл жүктеу/TXT жасау/preview және толық есептер.

web/account.js
Профиль, пароль, аккаунт бұғаттау және қолдау хаттары.

web/print.css
A4 бет, қайталанатын кесте тақырыбы, баспа жиектері.

web/print.js
Сурет пен қаріп дайын болғанда стандартты print терезесін ашады.

database/01_create_database.sql
17 кесте, 21 FK, индекстер, view, функция, рәсімдер және триггерлер.

database/02_seed_catalogs.sql
Тек анықтамалық оқу деректері; клиент/аккаунт/тапсырыс жасамайды.

database/03_verify.sql
SSMS-та нақты сайт дерегін JOIN/SELECT арқылы тексеру.

tests/test_integration.py
Нақты SQL Server интеграциялық және қатар орындалу сынақтары.

tests/test_installer.py
Қауіпті reset аттарын, backup қатесін және GO тоқтауын unit деңгейде тексереді.

tools/build_pages.py
Төрт статикалық HTML entry point-ті қайта құру құралы; күнделікті іске қосуға қажет емес.

tools/build_document.py
Осы Word құжатының генераторы.

tools/build_diagrams.py
21 FK байланысын үш ER көрінісіне салады.

tools/package_project.py
Құпия файлдарды қоспай ZIP жасап, SHA256 арқылы тексереді.

tools/check_frontend.mjs
JavaScript синтаксисі мен үш тіл кілттерінің толықтығын тексереді.

tools/export_schema.py
SQL sys каталогынан құжатқа арналған метадеректерді шығарады.

tools/ui_sandbox.py
Браузер QA үшін бөлек уақытша SQL база және 5001 порты; жұмыс базасын толтырмайды.
