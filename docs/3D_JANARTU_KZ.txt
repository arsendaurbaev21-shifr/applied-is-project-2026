3D МАРШРУТ КАРТАСЫ
Басты беттегі «3D маршрут картасы» сілтемесін басыңыз.
Қалалар арасындағы бағытты таңдаңыз. Калькулятордағы бағыт та өзгереді.
Тінтуірмен немесе саусақпен сүйреп айналдырыңыз. + және − масштабты өзгертеді.
«Қалпына келтіру» бастапқы көріністі қайтарады. Пернетақта бағыттауыштары да жұмыс істейді.
Карта SQL каталогындағы бағыттар мен қашықтықтарды пайдаланады.
Қала орталықтарының координаттары жуық. Жаңа қала үшін web/route-map.js ішіндегі
cityCentres тізіміне longitude, latitude мәндерін енгізу керек. Координат жоқ болса,
интерфейс оны хабарлайды. Бұл GPS емес; бағыт сызығы нақты жолды қайталамайды.
WebGL қолжетімсіз болса, бағыт тізімі мен қашықтық жұмысын жалғастырады.

ЖЕТКІЗУ ДЕРЕКТЕРІ
Клиент → «Жаңа тапсырыс»: жіберуші мен алушының аты-жөні, телефондары,
алу және жеткізу мекенжайлары, алу уақытының аралығы міндетті.
Телефонда 7–15 цифр; уақыттың соңы басталуынан кейін болуы керек.
Уақыт сол күннің Қазақстандағы жергілікті уақытымен енгізіледі.
Әкімші өзгертуге рұқсат етілген тапсырыстың деректерін түзете алады.
Бұрынғы тапсырыстарда енгізілмеген жаңа өрістер «—» болып көрінеді.
Жеткізу деректері тапсырыс карточкасы мен оның баспа нұсқасында бар.

БАҚЫЛАУ СІЛТЕМЕСІ
Тапсырыс карточкасының төменгі жағында «Бақылауды ашу» және «Сілтемені көшіру» бар.
Сілтемені ашу үшін аккаунтқа кіру талап етілмейді. Ол бағытты, мәртебе тарихын,
алу күнін және рейс жоспарланған болса болжамды жеткізу уақытын көрсетеді.
Телефондар, мекенжайлар, клиенттің аты, құжаттар және төлемдер ашық жауапта жоқ.
Әр тапсырыстың 64 таңбалы кездейсоқ бақылау коды бар. Тапсырыс нөмірі кодтың орнына жүрмейді.
Жаңарту үшін бақылау бетіндегі «Жүкті бақылау» батырмасын басыңыз.
127.0.0.1 сілтемесі тек осы компьютерде ашылады. Басқа адамдардың құрылғысынан
кіру үшін бөлек жариялау немесе қайта рұқсат берілген уақытша сыртқы сілтеме керек.

ХАБАРЛАНДЫРУЛАР
Жаңа өтінім және клиент тоқтатқан тапсырыс туралы белсенді әкімшілерге хабар келеді.
Әкімші мәртебені, рейсті немесе жеткізу деректерін өзгерткенде клиентке хабар келеді.
Жоғарғы «Хабарландырулар» батырмасы немесе сол мәзірден тізімді ашыңыз.
«Ашу» тиісті тапсырысты ашады. «Оқылды» және «Барлығын оқылды деп белгілеу» SQL-де сақталады.
Көрініп тұрған кабинетте оқылмаған хабар саны 30 секунд сайын тексеріледі.
Тізімді жаңарту үшін жоғарғы «Хабарландырулар» немесе «Жаңарту» батырмасын басыңыз.
Бұл сайт ішіндегі хабарлар; SMS, WhatsApp және браузер push хабарламалары қосылмаған.

БАСҚА ОРНАТУДЫ ЖАҢАРТУ
1. Жұмыс істеп тұрған сервер терезесінде Ctrl+C басыңыз.
2. Өз .env файлыңызды сақтап, жаңартылған кодты орналастырыңыз.
3. UPDATE_DATABASE.bat ашыңыз. Ол COPY_ONLY + CHECKSUM резервін жасап,
   RESTORE VERIFYONLY арқылы тексереді, содан кейін өзгерістерді транзакциямен қолданады.
4. Қате болмаса START.bat ашыңыз, браузерде Ctrl+F5 басыңыз.
5. /api/health: schemaVersion=2, tables=18, ok=true болуы керек.
Жаңарту кезінде FIRST_RUN.bat ішіндегі RESET таңдалмайды.
Жаңа компьютерде алғаш орнату үшін FIRST_RUN.bat қолданылады; жаңарту SQL-і оған қосылған.
SSMS-та dbo.Orders жаңа өрістері мен dbo.Notifications кестесін Refresh арқылы көресіз.

ТЕКСЕРУ
49 pytest тексерісі нақты SQL Server уақытша базаларында өтті.
Қайта миграция, жаңа өрістердің валидациясы, транзакциялық кері қайту,
басқа клиенттің деректеріне тыйым, ашық бақылаудағы жеке дерек шектеуі,
жеке хабарларды оқу және CSRF тексерілді.
Браузерде өтінім → әкімші хабары → растау → клиент хабары → ашық бақылау тексерілді.
3D бағыт таңдау, пернетақтамен айналдыру, масштаб, 390 px телефон көрінісі тексерілді.
SQL backup тестінің көшірмесі SQL Server Backup қалтасында қалды: Windows оны
жоюға рұқсат бермеді. Бұл тест нәтижесіне әсер етпейді.
